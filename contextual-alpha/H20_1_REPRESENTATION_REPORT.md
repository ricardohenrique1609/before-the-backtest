# H20.1 — Context Representation Feasibility: Report

**Verdict: PARTIAL PASS.** 18 of 25 pre-registered C1–C3 features are eligible for H20.2. All of
them are deterministic counts, flags or as-of macro values with complete provenance and zero
point-in-time violations. **R4** (as-of values) **PASS**; **R1** (flags) and **R2**

remain DATA-GATE FAIL / UNTESTED from H20.0 and were not used.

## 5. Transform-time PIT

Every item is classified (`H20_1_TRANSFORM_PIT_AUDIT.csv`): 25 / 25 built features **PIT_SAFE**,
6 / 6 classifiers PIT_SAFE, R3 candidates 1 PIT_SAFE (GDELT V2Tone, computed by GDELT at ingest),
**3 NON_PIT**, **3 UNRESOLVED**.

| R3 candidate | class | why |
|---|---|---|
| current LLM extraction (Claude, GPT, …) | NON_PIT | trained on corpora past every `t`; recorded as NON_PIT_TRANSFORM_CANDIDATE only |
| current sentence embeddings | NON_PIT | training post-dates most or all `t` |
| TF-IDF / topics fitted on 2018–2026 | NON_PIT | IDF and vocabulary use documents after early `t` |
| expanding-window TF-IDF refit at each `t` | UNRESOLVED | PIT by construction, but the mapping changes with `t`, so equal values do not mean the same thing across eras |
| TF-IDF on a frozen pre-2018 corpus | UNRESOLVED | would be PIT-safe if the cutoff were verified; no such corpus exists in the project |
| pre-2018 static word embeddings (GloVe 2014, word2vec 2013) | UNRESOLVED | training data predates `t`, but the third-party cutoff is asserted, not verified, and no hash-pinned copy exists |

No LLM, embedding or fitted text model was used for any feature. A test fails the build if an H20.1
script imports one.

## 15. Unresolved blockers

1. **GDELT crypto semantics (C3).** The inherited GDELT tag fails precision (0.68). A stricter rule
   (e.g. crypto theme plus a crypto term in the URL or organisations) would be a new representation.
   It needs its own pre-registration and a fresh audit sample; it was not tuned here.
2. **No systemic crypto-stress representation.** K5 had zero positives in 105 weeks of Wikipedia
   current events. C3 "systemic" content is therefore not represented by any eligible feature. Only
   generic crypto attention (F23) and US regulatory attention (C2) are.
3. **R3 has no PIT-safe text model.** Any text representation would need a frozen, hash-pinned
   model whose training cutoff predates every `t` (UNRESOLVED candidates X05/X06), or a separate
   stability design for expanding-window fits (X04).
4. **CFTC 2021–2026 blocked** (HTTP 429), so F17 stays out.
5. **Semantic labels are agent-produced.** A human re-annotation of the 272 audit items is
   recommended before H20.2 relies on K1a/K1b/K2/K3/K4.
6. **Inherited conditions.** C2 is US-only, C3 language bias persists (flat translingual crypto rate),
   and Fed/SEC publication frequency declines ~1.5× across eras. H20.2 must evaluate era-stratified
   and must not generalise beyond the US / English boundary.

**STOP.** H20.2 is not begun. No outcome was loaded. No predictive model was trained.
