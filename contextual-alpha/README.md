# Contextual Alpha

**Working paper:** *Beyond Market Data: Does Point-in-Time Public Context Add Incremental Predictive
Signal?*

A research project inside Quant Intelligence, scientifically separate from the frozen *Before the
Backtest* paper and H1–H19. Its long-run question: does genuinely contemporaneous public context add
out-of-sample predictive information beyond structured market and venue data (Model A market only,
Model B context only, Model C both; the object is the increment from adding context). A null or
negative answer is acceptable.

## Rules this project keeps

- Writes only inside `Contextual Alpha/`; everything else in Quant Intelligence is read-only.
- Information at `t + 1 minute` is future information. Day-only documents are admitted from the next
  local midnight.
- No outcome is read while choosing sources, collecting or classifying; the one lifecycle flag used
  (for the survivorship audit) is read in a sealed stage after all collected tables are hashed.
- `identifier ≠ identity`: tickers are versioned attributes; names come only from documents
  available at `t`.
- A data-gate failure is UNTESTED, never an economic REJECT.
