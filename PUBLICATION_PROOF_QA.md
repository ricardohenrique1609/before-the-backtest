## 1. Mathematics

Every expression the RC2 build degraded now sets as mathematics. Verified in the rendered page, not
only in the source.

| expression | RC2 | RC3 |
|---|---|---|
| support definition | `S_e = \|{ c C(t_e) : M(e,c,t_e)=1 }\|` — membership symbol **lost**, set in text | $S_e = \bigl\|\{c \in C(t_e) : M(e,c,t_e) = 1\}\bigr\|$ — **renders with ∈ and proper set braces** |
| indicator | `I_e = 1[S_e ≥ m]` in text | $I_e = \mathbf{1}[S_e \ge m]$ — bold indicator, math inequality |
| implied sample | `N* = _e I_e` — **summation sign lost** | $N^{*} = \sum_e I_e$ — **renders with ∑** |
| stop rule | `N* < N_min` in text | $N^{*} < N_{\min}$ |
| bounds | `N* ≤ 15`, `N* ≤ 16`, `m ≥ 3`, `N_min > 15`, `N_min > 16` in text | all in math, with `\le`, `\ge` and a true `\min` subscript |
| identifiers | `S_e`, `I_e`, `t_e`, `C(t_e)`, `M(e,c,t)` typewritten with literal underscores | all italic math |
| `N*` in code spans | typewriter `N*` | math $N^{*}$ — **12 occurrences**, the only remaining typewriter `N` is the verdict label `NO_TEST`, which is correct |

**Unicode:** `∈ ∑ ≤ ≥ Δ − ≈ → ↔ §` and the circled S in USDⓈ-M all render. `CEX↔DEX` keeps its arrow.

**Accented author names.** `Będowska-Sójka` printed as **"Bdowska-Sójka"** in the first RC3 build —
the ogonek was dropped silently by the font. Accented characters are now emitted as LaTeX accent
commands rather than raw bytes, and the name renders correctly. **A dropped diacritic misspells a
cited author, so this was treated as a defect, not a cosmetic issue.**

## 2. Lists

| location | RC2 | RC3 |
|---|---|---|
| §2.3 procedure box | the six steps were **joined into one paragraph**; the list did not survive inside the block quote | numbered list 1–6, intact, inside the quote |
| §2.6 three components | **all three items numbered `1.`**, with continuation lines split off as separate paragraphs | **1, 2, 3**, each item whole |

Root cause in both: the historical converter closed a list at any line that was not itself an item,
so a wrapped item restarted the numbering, and a `>` quote joined its contents. The release converter
now folds indented continuation lines into their item and renders quotes recursively.

**A note on two patterns.** Correctly typeset mathematics does not extract as the source characters:
Computer Modern's `\sum` extracts as "P", and `^{*}` extracts as U+2217 ASTERISK OPERATOR rather than
ASCII `*`. The audit accepts those forms **deliberately and with the reason recorded in the script**,
because rejecting them would flag correct output. The glyphs themselves were confirmed by eye on
page 4.

## 7. Open item: author metadata — blocker B7

**No authoritative author identity exists in the repository or in the release configuration.** The
only name available is a git commit identity, which is a configuration value, not an authorised
byline. Inferring a public author from it, or inventing an affiliation, is exactly the kind of
fabrication this project's rules forbid.

The title page therefore reads **`AUTHOR_METADATA_REQUIRED`**, and the same placeholder stands in
`CITATION.cff` and `zenodo.json`. The build prints a warning whenever it is used.

> **The paper must not be published while B7 is open.** Resolving it requires the author to state the
> name, and separately to decide on affiliation, ORCID and correspondence address — none of which is
> inferred here.

## 8. Remaining limitations of this QA

- Text extraction reflects font character mapping, not the source; math and ligatures extract with
  substitutions, which is why visual confirmation was done as well.
- The pixel check detects ink in margin bands and blank pages. It cannot judge typographic quality.
- A bulleted list inside a block quote still renders as inline hyphenated text in one place; content
  is unaffected and it is recorded rather than fixed.
