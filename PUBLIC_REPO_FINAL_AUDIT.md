## 2. Excluded, deliberately

Nothing is copied by wildcard from outside the paper directory, so no file can be swept in by
accident. The whole of the research repository other than the paper, its evidence and its registry
is absent: strategy and infrastructure code, notebooks, the raw and derived data outside the nine
cited artefacts, caches, the virtual environment, and the LaTeX toolchain.

| excluded | why |
|---|---|
| `data/` (except the 9 cited artefacts) | raw and intermediate corpora; `DATA_RELEASE_POLICY.md` classifies every source |
| `.venv/`, `.tools/` | environment and toolchain, reconstructed from `requirements.txt` and `BUILD.md` |
| `paper.log` | LaTeX build log, regenerated by any build |
| `_references_section.md` | build intermediate, written into `paper.tex` by `release_refs.py` |
| `PUBLIC_RELEASE_PLAN.md` | internal sequencing, including steps deliberately **not** taken |

`.gitignore` in the published package keeps `data/`, `.venv/`, `.tools/`, `.env` and build output out
of it permanently.

### The contact address

`scripts/h19_2_prefreeze.py` and `scripts/h19_1_feasibility.py` identify themselves to SEC EDGAR and
to the venue archives, as those fair-access policies require. The published copies read
`QIE_CONTACT_EMAIL` from the environment and **refuse to run without it**. There is deliberately no
fallback: a placeholder address would be a false identification. The author's personal address
appears **zero** times.

### Author metadata

The byline is **Ricardo H. Ramos Silva**, **Independent Researcher**. No employer or university
affiliation is stated and **no institutional endorsement is implied**. No ORCID, because none was
provided and none is invented. No correspondence address is published. The name is defined once, in
`scripts/release_metadata.py`, and every file that prints or records it reads from there.

Three release QA documents previously named an organisation while reporting that its matches were a
publicly listed issuer in a takeover-offer dataset rather than employer data. The finding is kept and
the name is removed, because printing it next to the word "employer" invites exactly the inference
the author excluded.

| check | result |

| frozen V1–V4 files published byte-identical to the accepted versions | **94 of 94**, verified by SHA-256 at build time; the build fails on any difference |
| frozen documents rewritten in any way | **none** — link rewriting is applied to the release documents only |

| `PUBLIC_REPO_MANIFEST.json` | SHA-256 and size of every published file |
| `RELEASE_MANIFEST.json` | the release package this was derived from, 79 files |
| published files tracked by git | **186 of 186** — the build fails if `.gitignore` would exclude any of them |

An unanchored `data/` rule in the package's `.gitignore` matched `figures/data/` at every depth and
silently left the fifteen per-figure source CSVs out of the first commit. Every rule is now anchored
to the repository root, and the build asserts that no published file falls under one.

The frozen version documents reference research-repository paths that are not published. That is
left visible rather than rewritten: editing a frozen document would break the hash its own freeze
record asserts, and the review trail is worth more intact than tidy.

## 6. What this package does not claim

- **No journal acceptance, no external peer review, no institutional endorsement.** The four referee
  reports are this project's own hostile-review process, and the package says so wherever they appear.
- **No DOI and no archival deposition.** `CITATION.cff` and `zenodo.json` carry prepared metadata
  with no live identifier. Nothing has been uploaded to Zenodo, SSRN or arXiv, and the work has not
  been submitted to a journal. A GitHub tag is not an archival identifier — see `RELEASE_BLOCKERS.md`
  item **B3b**.
- **No independent replication.** One researcher, one codebase, one venue — blocker **B6**, disclosed
  in the paper itself.
- **No profitability claim.** No return, carry, P&L or Sharpe ratio is computed anywhere in this
  paper.
